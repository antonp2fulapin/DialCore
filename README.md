# DialCore Marketing Site

A premium marketing website for DialCore, a next-generation VoIP/SIP calling provider. Built with Next.js 14 (App Router), TypeScript, Tailwind CSS, shadcn/ui patterns, and Framer Motion.

## Getting Started

```bash
npm install
npm run dev
```

The site is production-ready for Vercel deployment. SEO metadata and Open Graph tags are included in `app/layout.tsx`.

## Features
- Hero with animated gradient and clear CTAs
- Feature preview grid with "Coming Soon" badges
- Request Access modal with modern form (logs submissions to the console)
- Responsive layout with glassmorphism styling and Framer Motion animations
- Minimal footer with contact information and policy placeholders
